Download & Install

Windows

  1. Download and run the installer below
  2. If Windows SmartScreen appears, click More info
  3. Click Run anyway
Download for Windows (.exe)

macOS

The app is unsigned. macOS will block it on first launch — use the Terminal command below to clear this once.

  1. Open the .dmg file
  2. Drag Albion Comp Builder to your Applications folder
  3. Open Terminal (Spotlight → Cmd+Space → "Terminal")
  4. Run the command below
  5. Open the app normally — you only need to do this once
xattr -cr /Applications/Albion\ Comp\ Builder.app
