Bulk edit

Bulk edit lets you change many loadouts at once instead of editing each one by hand — ideal for applying a shared weapon, swapping a cape across a whole comp, or renaming a batch of templates.

Opening bulk edit

Bulk edit works in two places, with the same editor:

  • In a composition — select multiple loadouts, then click Bulk Edit.
  • In Loadout Templates — select multiple templates, then click Bulk Edit.

How each slot behaves: leave unchanged, set, or clear

Every slot in the bulk editor has three possible actions:

  • Leave unchanged (the default) — the slot is not touched on any selected loadout; each keeps whatever it already had.
  • Set — choose an item, tier, and enchant to apply to that slot on all selected loadouts.
  • Clear — empty that slot on all selected loadouts.

Because the default is "leave unchanged", you only affect the slots you deliberately touch.

Reading the shared state

Each slot shows the current state across your selection so you know what's shared before you change anything:

  • Empty — the slot is empty on every selected loadout.
  • Unanimous — every selected loadout has the same item in that slot.
  • Mixed — the selected loadouts differ in that slot.

What you can bulk edit

The editor covers gear slots, inventory slots, spell selections, and meta fields (each loadout's name and role). Changes are staged as you go.

Applying changes

Click Apply to write every staged change to all selected loadouts at once. Slots left as "leave unchanged" keep each loadout's existing value.
