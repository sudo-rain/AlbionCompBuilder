Building a composition

A composition is a set of loadouts you plan together — typically one per role or player slot in a ZvZ party. This page covers the full build workflow.

The Dashboard

The Dashboard lists every composition you've saved. From here you can create a new composition, open an existing one to edit it, or delete ones you no longer need. Compositions are stored locally on your machine.

The composition view

Opening a composition shows all of its loadouts together. Add loadouts, give each a role, and open any loadout to edit its gear. Selecting multiple loadouts reveals the Bulk Edit action.

The three-pane builder

Editing a loadout opens the builder, which is split into three panes:

  • Slot grid (left) — every equipment slot: weapon, off-hand, head, chest, boots, cape, mount, and consumables. Click a slot to edit it.
  • Item browser (center) — search and filter items valid for the selected slot, then click to equip. Choose the tier and enchant level.
  • Ability detail (right) — shows the abilities and stats for the equipped item. It is inline and always visible — not a hover tooltip — so you can read spell details while you build.

Equipping items, tiers, and enchants

Select a slot, pick an item in the browser, and set its tier (T4–T8) and enchant level. The loadout updates immediately and the ability pane reflects the new item.

Inventory slots

Beyond equipped gear, each loadout has inventory slots for the items a player should carry — swaps, potions, and food. Inventory items are edited the same way as equipped slots.

Reading spell and ability detail

The ability pane lists a weapon's abilities by row (Q / W / E / R / D / F and passives). Where an item offers a choice, pick the spell you intend to run; the description and stats update so you can compare options without leaving the app.
