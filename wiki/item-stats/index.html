Item stats & abilities

Every loadout card, item browser, and ability detail pane surfaces numbers so you can compare options at a glance. This page explains what each number means and how to read them.

Reading the loadout notation

Each loadout card shows a compact gold notation line summarising the spell selections across all ability-bearing slots, for example: Q2·W3·P1  /  D1·P2  /  R3·P1  /  F2·P1.

The format is row letter + 1-based option number, tokens separated by · within a slot and   /   between slots. Slots appear in the order Main Hand / Helm / Chest / Boots — only slots that actually carry ability rows appear in the notation.

Row letters map to keybinds in-game:

  • Q, W — active abilities from the main-hand weapon (E is always the weapon's default ability and is not notated)
  • D — helm active ability
  • R — chest active ability
  • F — boots active ability
  • P — passive rows (all passive rows share the P prefix; they are numbered sequentially)

See Building a composition for the builder itself.

Spell numbers in the ability detail pane

Selecting an ability in the builder's right-hand detail pane shows a description and a stat table beneath it. Each row in the table is a stat (Damage, Duration, Radius, Cast Time, and so on) with the value resolved for the item's current tier and enchantment level. Items with combo attacks list per-hit values across multiple columns.

The values update automatically whenever you change the Tier or Enchantment dropdowns in the item browser — you do not need to re-select the spell.

Off-hand, armor, and cape stats

Off-hands, armor pieces (helm, chest, boots), and capes do not have active abilities to choose, so their ability detail pane shows an item stat table instead — rows such as armor, magic resist, hitpoint bonus, max energy, or cast time reduction. The values shown reflect the base item power for the selected tier and enchantment; changing the Tier or Enchantment dropdowns updates the table immediately. The same stat table also appears in the Bulk Edit detail pane when an off-hand or armor piece is selected.
